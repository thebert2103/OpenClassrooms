# Projet 8 : Analyser les indicateurs d’égalité femmes/hommes en respect du RGPD

## &#128203; Scénario
Data analyst dans un cabinet de conseil en transformation digitale, je suis chargé d’aider la DRH à automatiser un rapport sur l’égalité professionnelle femmes/hommes à partir de données RH non anonymisées

## &#127919; Objectifs
- Automatiser un diagnostic égalité femmes/hommes via un workflow KNIME.
- Calculer plusieurs indicateurs clés et générer les graphiques associés.
- Produire un fichier .csv propre et anonymisé pour un usage futur dans Tableau.
- Garantir la conformité RGPD et documenter une méthodologie reproductible.
## &#128295; Outils utilisés
- KNIME (workflow, traitements, agrégations, anonymisation/pseudonymisation, calculs)
- Référentiels officiels (indicateurs égalité femmes/hommes, ministère du Travail)

## &#127891; Compétences acquises
- Conception d’un workflow KNIME pour automatiser un diagnostic RH
- Collecte, agrégation et préparation de données issues d’un SIRH
- Mise en conformité avec le RGPD : anonymisation/pseudonymisation, minimisation des données
- Calcul et suivi d’indicateurs d’égalité femmes/hommes (dont un score global)
- Contrôles de cohérence et qualité des données (vérifications, règles métiers)
- Génération de sorties réutilisables : fichier .csv prêt pour Tableau
- Structuration et présentation d’une analyse à un large public (plénière)
- Formulation de recommandations concrètes pour améliorer le score d’égalité l’année suivante
