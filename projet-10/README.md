# Projet 10 : Réaliser une étude sur l’accès à l’eau potable

## &#128203; Scénario
Consultant Data Analyst pour l’ONG DWFA, je suis chargé de produire un tableau de bord permettant d’identifier les pays en difficulté d’accès à l’eau potable et ceux prioritaires pour les futurs investissements du bailleur de fonds.

## &#127919; Objectifs
- Sélectionner et préparer les indicateurs clés liés à l’accès à l’eau potable.
- Construire un tableau de bord clair et accessible en 3 vues.
- Identifier les pays prioritaires pour guider les investissements de l’ONG.
## &#128295; Outils utilisés
- Power BI
- Power Query (nettoyage et automatisation de la préparation des données)
- DAX (mesures, calculs, KPIs)
- Sources externes : OMS, FAO, datasets fournis par le Data Engineer

## &#127891; Compétences acquises
- Recherche, sélection et enrichissement d’indicateurs pertinents
- Prétraitement, nettoyage et manipulation de données multi-sources
- Création de visualisations claires, accessibles et orientées aide à la décision
- Construction d’un dashboard multi-vues
- Data storytelling : structuration d’un message impactant pour un bailleur de fonds
- Conception d’un dashboard optimisé à partir de besoins métier complexes
- Formalisation professionnelle : synthèse, mockups, justification des choix
