# Projet 11 : Produire une étude de marché internationale

## &#128203; Scénario
Data Analyst chez La Poule qui Chante, à partir des données historiques de la FAO et d’autres sources (World Bank Group, Open Data), je suis chargé d’étudier les opportunités d’expansion à l'internationale.

## &#127919; Objectifs
- Collecter et consolider des données internationales (FAO + open data).
- Réaliser une ACP puis un clustering pour regrouper les pays.
- Formuler des recommandations stratégiques pour l’expansion internationale.

## &#128295; Outils utilisés
- Python (Pandas, NumPy, Matplotlib, Seaborn, PLotly, Scikit-learn, SciPy)
- Jupyter Notebook
- Sources open data : FAO, World Bank Group, Open Data

## &#127891; Compétences acquises
- Recherche de données pertinentes via une analyse PESTEL
- Fusion, préparation et nettoyage de jeux de données multi-sources
- Construction d’un dataset international (150+ pays, >60% population mondiale)
- Analyse exploratoire approfondie
- Réduction de dimensions (ACP) : cercles de corrélations, projection des individus
- Clustering : CAH + k-means, interprétation des groupes de pays
- Recommandations stratégiques d’expansion à destination d’un COMEX
- Communication vulgarisée pour un public non technique
