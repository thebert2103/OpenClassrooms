# Projet 12 : Détecter des faux billets

## &#128203; Scénario
En mission pour l’Organisation Nationale de Lutte contre le Faux-Monnayage (ONCFM), j’ai développé un modèle de machine learning capable de prédire si un billet est vrai ou faux à partir de ses dimensions.

## &#127919; Objectifs
- Explorer, nettoyer et modéliser des données réelles de billets.
- Comparer plusieurs modèles de classification pour détecter les faux billets.
- Développer une application Python capable de prédire la nature d’un billet.

## &#128295; Outils utilisés
- Python (Pandas, NumPy, Matplotlib, Seaborn, Plotly)
- Scikit-learn (Régression linéaire, Régression logistique, KNN, Random Forest, K-Means)
- Jupyter Notebook
- Streamlit (application de prédiction)

## &#127891; Compétences acquises
- Analyse exploratoire et visualisation des dimensions des billets
- Nettoyage et préparation du dataset, gestion des valeurs manquantes (régression linéaire)
- Construction, comparaison et évaluation de différents modèles de classification
- Sélection du meilleur modèle (métriques, interprétabilité, performances)
- Extraction des features les plus discriminantes pour détecter un faux billet
- Développement d’une application Python de prédiction opérationnelle
- Présentation des résultats : méthodologie, modèles testés, justification du choix final
